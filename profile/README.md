# Inside Machines

**Open the box, see how it moves.** Short explainer videos about real machines, from a pendulum to the damper inside
Taipei 101, each with a page you can play with. Everything is made in Blender, and the tools we make it with are open
source.

## Open source

**[blender-shorts-agent](https://github.com/goinsidemachines/blender-shorts-agent)**: a Claude Code plugin that
takes one idea to a finished, narrated vertical explainer short made entirely in Blender, with story and storyboard
pages to approve and checks on every rendered frame. Every short above was made with it. MIT licensed.

## Get in touch

Ideas, bugs and questions go in the plugin's
