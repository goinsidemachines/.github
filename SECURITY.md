# Security

## Reporting a problem

Please report security problems privately through GitHub: on the affected repository, open **Security → Report
a vulnerability**. Don't open a public issue for them.

You'll get a reply within a week. Once a fix is released, the report is credited to you unless you'd rather not.

## What counts

Anything that lets our software do something its user didn't approve: download or run code, send data anywhere its
README doesn't name, read or leak a key, or write outside the folders it says it uses.

## Supported versions

Only the latest release gets fixes.
